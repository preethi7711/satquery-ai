# SIH Demo Execution Guide

## Setup
1. **Backend**: Open terminal, activate `venv`, run: `python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000`
2. **Frontend**: Open terminal, `cd frontend`, run `npm run dev`. Navigate to `http://localhost:5173`.

---

## Demo 1: Single-Image VQA
1. Drag and drop **1** Remote Sensing image (Optical or SAR).
2. Enter Query: *"Describe the major land-cover types visible in this image."*
3. **What to highlight to Judges**:
   - The trace verifies exactly 1 image.
   - The LLM selected the `RS_VQA` task autonomously.
   - No raw prompt templates are leaked.

## Demo 2: Bi-Temporal Hero Demo (Change Analysis)
1. Drag and drop **2** Images (Before and After).
2. Enter Query: *"What changed between these two images, and where did the change occur?"*
3. **What to highlight to Judges**:
   - The trace shows the Agent dynamically switching to `CHANGE_ANALYSIS` due to detecting 2 files and a change intent.
   - Wait for inference to finish.
   - Scroll down to view the **Visual Change Evidence** overlay generated by the backend and streamed to the UI.

## Demo 3: Optical + SAR Fusion
1. Drag and drop **1 Optical** and **1 SAR** image.
2. Enter Query: *"Use the optical and SAR images together to identify built-up and water-covered regions."*
3. **What to highlight to Judges**:
   - Trace shows `OPTICAL_SAR_FUSION`.
   - Extracted evidence explicitly shows data derived from both modalities simultaneously (e.g. Backscatter + Brightness).

## Demo 4: Graceful Failure Handling (Constraint Guardrails)
1. Upload **1** Image.
2. Enter Query: *"What changed?"*
3. **What to highlight to Judges**:
   - Instead of crashing or hallucinating change on one image, the Orchestrator's input validator intercepts the mismatch, halts the pipeline, and returns a UI error explaining that 2 images are strictly required.
