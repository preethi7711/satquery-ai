# Dataset Strategy & Handling

## 1. Remote-Sensing Adaptation (BigEarthNet)
- **Status**: Targeted for Phase 4 adaptation.
- **Handling Protocol**: Due to hardware constraints (16GB RAM, RTX 3050), full downloading and training on the 100GB+ BigEarthNet archive is restricted.
- **Implementation**: We utilize a streaming/subset approach via `datasets` or highly localized mock subsets generated by `scripts/download_dev_subset.py`.

## 2. Dev & Test Data (`data/raw/`)
The system expects GeoTIFF files natively but is capable of processing benchmark RGB `.jpg` or `.png` files through the PIL pipeline.
- `dev_optical_1.tif`
- `dev_sar_1.tif`
- User-supplied JPGs (e.g. `i12.jpg`)

## 3. Storage Hierarchy
```text
data/
├── raw/         # User uploads and original imagery
├── processed/   # Generated masks, localized overlays (Served to Frontend)
└── models/      # Local LoRA weights and HF caches
```
*Note: Large datasets and processed outputs are ignored via `.gitignore`.*
